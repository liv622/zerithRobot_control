# 通用机器人仿真与示教框架（E1-PRO 插件）

这是一个基于 PyRoki + Viser 的可扩展机器人仿真与示教框架。当前内置
E1-PRO 插件；程序显示 E1-PRO 整机模型，但逆运动学只优化 7 个机械臂关节。
启动时自动读取 `e1_pro_full/urdf` 中最新修改的 `E1-PRO*.urdf` 文件。

项目采用分层结构：轨迹算法、交互应用、通信适配器、Viser 仿真界面、Web
示教器和持久化实现均为根目录平级包，具体机器人型号位于 `robots/` 插件目录。
根目录的两个脚本只负责启动。目录职责、依赖方向以及新增机器人、MOVC、ROS 2
或数据库实现时的放置规则见
[`ARCHITECTURE.md`](ARCHITECTURE.md)。

运动学参数、关节轴和限位由上述真实 URDF 在启动时读取，不使用近似 DH 参数。
安装完整依赖后默认使用 PyRoki；未安装 PyRoki 时，headless smoke test 可使用
SciPy 后备求解器，以便先检查模型文件和基础环境。

## 真实 TCP 求解点

IK 目标不是 `Link7_L` 原点，而是整机 URDF 中的：

```text
Link7_L
  └─ zhijian_joint (fixed, xyz = 0 0 0.17167)
       └─ zhijian_link   <-- TCP / IK 目标
```

也就是相对 `Link7_L` 沿局部 `+Z` 方向延伸 `171.67 mm` 的图中指尖点。

## IK 与其他机构的关系

IK 仅优化：

- `Joint1_J`
- `Joint2_J`
- `Joint3_J`
- `Joint4_J`
- `Joint5_J`
- `Joint6_J`
- `Joint7_J`

以下关节可在界面中单独控制，但它们的 Jacobian 列始终为 0，不会被
IK 自动改动：

- `platform_joint`：机械臂/平台升降
- `box01_joint`：料箱 01 横移
- `left_dainchi_joint`：左电池升降
- `right_dianchi_joint`：右电池升降
- `boxs02_joint`：料箱 02 斜向移动

## 启动构型

程序启动以及点击 `整机与目标回到初始值` 时使用以下构型：

| 关节 | 初始值 (rad) |
| --- | ---: |
| `Joint1_J` | 0.00 |
| `Joint2_J` | -0.50 |
| `Joint3_J` | 0.00 |
| `Joint4_J` | -2.00 |
| `Joint5_J` | 0.00 |
| `Joint6_J` | -0.61 |
| `Joint7_J` | 0.00 |
| `platform_joint` | 0.00 |
| `left_dainchi_joint` | 0.00 |
| `right_dianchi_joint` | 0.00 |
| `boxs02_joint` | 0.00 |

其余非机械臂关节继续使用 URDF 默认值。程序启动时会检查这些配置是否位于最新
URDF 的关节限位内。

默认开启实时求解。改动六轴 TCP 或其他机构滑块时，程序会合并密集事件并
始终求解最新目标，不会排队执行过期的中间状态。

## 安装

推荐使用 Python 3.11。同事拿到完整项目文件夹后，在终端执行：

```bash
cd e1pro
python3.11 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip setuptools wheel
python -m pip install -r requirements.txt
python app.py --smoke-test
```

Windows PowerShell 以及局域网访问的完整步骤见
[`INSTALL.md`](INSTALL.md)。安装使用 `requirements.txt`。

## 运行

```bash
cd e1pro
source .venv/bin/activate
python app.py --robot e1pro
```

打开终端中 Viser 打印的 HTTP 地址。如果 `8080` 被占用，Viser 会自动使用
`8081` 等其他端口。

## 固定式工业示教器

示教器脚本会自动启动对应的 Viser 仿真进程，并在通信接口就绪后打开示教器页面。
正常使用时只需要运行一个脚本：

```bash
# 自动启动仿真 + 固定示教器页面
python teach_pendant.py --open
```

退出示教器时会自动关闭它启动的仿真进程。如果需要连接已经单独运行的仿真，使用：

```bash
python teach_pendant.py --no-simulator --sim-url http://127.0.0.1:8765 --viser-url http://127.0.0.1:8080
```

示教器会在首页、运动、示教程序、仿真和配置页面右侧常驻嵌入 Viser 三维场景，
诊断页面则隐藏仿真窗口以扩大诊断区域。Viser 只负责实时显示机器人模型，不再
提供运动按钮、参数控件或场景拖拽；所有操作统一从 zerithRobot 示教器完成。
示教模块可以通过顶部“收起模块”按钮隐藏，展开后恢复当前页面。
每个主页面顶部还提供子模块复选框，默认全部打开。例如“运动”页面包含“运动”、
 “运动设置”和“仿真界面”三个子模块；示教程序和配置页面也可以分别隐藏点位编辑、
轨迹参数、配置文件等子模块，设置保存在浏览器本地。隐藏功能子模块后，中间功能子页面
会收缩，释放的布局空间自动分配给右侧 Viser 仿真；其它可见功能仍保持可操作，文字不会
被仿真窗口遮挡。隐藏“仿真界面”则由功能页面占满右侧区域。
如果 Viser 使用了其他端口，可通过以下参数告诉示教器：

```bash
python teach_pendant.py --open --viser-url http://127.0.0.1:8081
```

也可以手动打开 `http://127.0.0.1:8090`。示教器采用固定 16:9 协作机器人布局，
不使用拖动滑块。主要功能按模块分为首页、运动、示教程序、配置和诊断页面：

- “运动”页面内提供笛卡尔、关节、零空间和附加轴四个子页面；
- 笛卡尔与关节方向键支持长按连续轨迹运动，松开立即停止；
- 零空间子页面锁定当前 TCP 六维位姿，并通过 PyRoki 让 7 轴关节沿冗余
  自由度连续联动；
- 关节子页面支持保持同一 TCP 位姿切换冗余臂型；
- “配置”页面支持全局速度百分比、最大线速度、最大角速度、最大关节速度和
  动作间延时；
- 当前速度、轨迹、IK 和臂型参考可以保存为配置文件并重新调用；
- “示教程序”支持 MOVL/MOVJ 点位保存、修改、勾选运行、循环执行和停止；
- “诊断”集中显示 IK 误差、可达性和最近运行消息。

示教器的关节点动会直接改变仿真关节，并把 TCP 目标同步到新的实际位姿；笛卡尔
点动则通过 IK 驱动仿真。底部的点动步长同时表示 `mm / deg`，可用
`×0.1 / ×1 / ×10` 快速切换。

笛卡尔和 J1–J7 的 `− / +` 按钮支持连续点动：鼠标或触摸按下后立即执行第一
小步，继续按住时以约 `20 Hz` 生成连续轨迹，松开即停止。指针移出按钮、触控
取消、浏览器窗口失焦或切换到后台也会自动停止。笛卡尔连续点动始终锁定完整
TCP 姿态约束；到达不可达区域或关节限位时会停止并在程序状态栏提示。

通信端口可分别配置：

```bash
python app.py --control-host 127.0.0.1 --control-port 8765
python teach_pendant.py --sim-url http://127.0.0.1:8765 --port 8090
```

默认控制接口只监听本机。需要局域网分机部署时才应把 `--control-host` 改为
`0.0.0.0`，并通过防火墙限制可信网段。

界面操作：

- `绝对目标`：直接输入 X/Y/Z（米）和 Roll/Pitch/Yaw（度），无人为位姿范围限制；
  也可以按住数值框右侧上下按钮连续调整。
- `调整速度` 使用 `0.5–30` 的连续滑块，最小步进为 `0.5`。滑块值同时表示
  位置的毫米步长和姿态的角度步长；例如设为 `2.5` 时，数值框上下按钮每次
  调整 `2.5 mm / 2.5°`。
- `场景 TCP 拖拽` 默认设为 `锁定`，避免误触。切换到 `解锁` 后，三维场景会
  先把控制器对齐当前实际 TCP，再显示世界根坐标下的平移和旋转控制器；拖动
  结果会同步写回绝对目标 XYZ/RPY，并在开启
  实时求解时持续触发 IK。内部始终保留拖拽生成的原始四元数，
  RPY 仅用于界面显示，因此在 `Pitch=±90°` 附近也不会因欧拉角分支切换而跳回。
- `实时求解`：默认开启；绝对目标数值变化时持续求解最新目标。
- `执行一次 IK`：在关闭实时求解时用于手动刷新。
- `目标设为当前 TCP`：把六轴滑块同步到当前实际 TCP，便于从当前姿态微调。
- `同时锁定 TCP 姿态` 关闭时：只检查目标点位置是否可达。
- `同时锁定 TCP 姿态` 默认开启：位置与姿态都必须满足。
- `其他机构联动控制`：编辑平台、料箱和电池的待执行位置。
- `机械臂关节参考引导`：在保持 TCP 目标优先的同时，用关节期望角引导求解器。

## 机械臂关节参考

界面里的关节角滑块是 IK 求解器的关节参考，不是直接覆盖 IK 结果的强制关节命令：

- 开启 `启用臂形引导` 后，移动一个或两个关节期望角，程序会实时寻找新的
  IK 解，同时优先保持 TCP 的位置和姿态。
- `当前解设为臂形参考` 会把求得的实际关节角设为新的偏好中心，适合
  找到大致臂形后继续细调。
- `引导强度` 默认是 `0.05`。如果臂形变化不明显可逐步增大；如果希望 TCP
  误差更小则减小。TCP 位姿约束始终拥有更高权重。
- 这一功能用于目视选择更合适的臂形和绕开明显碰撞；当前版本没有自动碰撞
  检测，因此仍需结合整机模型检查连杆、料箱和机架之间的间隙。

## 卡住恢复与手动重新求解

局部 IK 如果从一个已经贴近关节限位的失败解继续求解，可能反复停留在同一个
坏解附近。`可达性` 面板提供以下恢复设置：

- `误差超限时自动多起点恢复` 默认开启。当局部解的位置误差超过 `2 mm`，或
  锁定姿态时角度误差超过 `1°`，程序会自动尝试多个初值。
- 恢复初值包括最后一次高精度可达解、初始解、当前臂形参考、关节中位构型、
  镜像构型和多组确定性的限位内采样。
- `恢复搜索种子数` 用于调整搜索广度；默认 `10`。数值越大越容易跳出坏的
  局部解，但一次恢复所需时间也会增加。
- `TCP 手动目标` 操作区中的 `刷新 IK / 多起点重新求解` 可以在 TCP 目标没有
  发生变化时主动刷新并重新执行多起点求解，适合当前解已经卡住时手动尝试。
  连续点击会更换随机种子批次，而不是反复搜索完全相同的一组初值。
- `本次 IK 尝试数` 和 `恢复状态` 会显示是否切换到了更优解。

其他机构关节在所有恢复尝试中都会硬锁定，恢复搜索只改变 7 个机械臂关节。

## MOVL / MOVJ 示教点

示教器右侧是持久化点表，不再使用起点、中间点和终点。调整机器人到需要记录的
位置后，选择数据类型并点击 `保存当前实际点位`：

- `MOVL` 保存实际 TCP 的 X/Y/Z（米）和 Rx/Ry/Rz（度），运行时执行笛卡尔空间
  直线位置插补和四元数姿态插补，并对全部采样点执行 IK 预检。
- `MOVJ` 保存实际 J1–J7 关节角（度），运行时在关节空间执行五次平滑插补，
  目标超出 URDF 关节限位时拒绝执行。

每个示教点自动获得 `P001` 形式的编号，也可以输入自定义名称。点击点表行或
`编辑` 后，可直接修改名称和点位数据；MOVL 行只显示笛卡尔数据，MOVJ 行只显示
关节数据。点位会自动写入项目根目录的 `teach_points.json`，重启后仍会加载。

每行最前面的复选框决定该点是否参与程序，鼠标单击即可勾选或取消。点击
`运行勾选示教点` 后，程序按点表从上到下执行所有勾选点；启用 `循环执行` 后会
反复执行同一组点，直到点击 `停止`。`单点时长` 表示每两个当前状态与目标点
之间的运动时间，MOVL 和 MOVJ 可以在同一个点表中混合排列。

MOVL 的位置误差超过 `2 mm`、姿态误差超过 `1°`，或相邻 IK 采样的任一关节
变化超过 `15°` 时，该点会拒绝执行并在状态栏显示原因。其他机构在示教程序
运行期间保持当前设定，不参与机械臂插补。

TCP 实际位置会显示一个坐标系和状态球：

- 绿色：可达。
- 红色：不可达。

默认位置可达阈值为 `10 mm`；锁定姿态时，姿态误差阈值为 `10°`。
这两个阈值只影响红/绿可达性提示，不会截断或限制 IK 求解。求解器仍保留 URDF
中的物理关节限位。

## 求解结果

每次求解会更新 `last_solution.json`，包含：

- TCP 目标位置和姿态。
- `reachable` 可达性结果。
- TCP 位置/姿态误差。
- 7 个机械臂关节的弧度值和角度值。
- 其他机构关节的当前位置。

## 快速验证

```bash
python app.py --smoke-test
```

该测试会验证整机网格与 URDF 加载、延伸 TCP 求解误差、同一 TCP 下能否得到
明显不同的冗余臂形、MOVL 姿态轨迹的连续求解，以及所有非机械臂关节在 IK
前后是否完全不变。
